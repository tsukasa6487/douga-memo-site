# App Privacy の回答

- 状態: 実装（posthog-react-native 4.85、@sentry/react-native 7.11、アプリ本体の `docs/spec/analytics.md`）と照合した回答。ソフトテニスタクティクスと同じ回答の形。App Store Connect への登録・公開は別途確認する。
- 最終更新: 2026-11-01

対象は PostHog・Sentry を含み、以下と一致するプライバシーマニフェストを持つ production ビルド。Apple の定義では、端末外へ送ってリクエスト処理を超えて保持する情報を収集と扱う。端末内の動画・線・メモ・購入状態の記録だけを根拠に、ユーザーコンテンツや購入履歴を「収集」とは回答しない。

|データ|申告|利用目的|ユーザーへの関連付け|追跡|
|---|---|---|---|---|
|識別子 / デバイスID|PostHog の匿名IDと Sentry のインストールIDを送るため申告|アナリティクス・アプリの機能|あり（同じインストールの情報を結ぶID）|なし|
|使用状況 / 製品の操作|仕様の操作イベント（作成・保存・再生・スロー・削除など）を申告|アナリティクス|あり（IDと一緒に送る）|なし|
|購入 / 購入履歴|購入画面の表示・購入・復元のイベントを送るため申告|アナリティクス|あり（IDと一緒に送る）|なし|
|診断 / クラッシュデータ・その他の診断|Sentry のエラー・クラッシュとネイティブ診断を申告|アプリの機能|あり（Sentry Cocoa のインストールIDに関連付く）|なし|
|診断 / パフォーマンスデータ|性能計測は無効。申告対象外|—|—|—|
|ユーザーコンテンツ（写真・動画・その他）|動画・線・メモは送信しない。申告対象外|—|—|—|
|位置情報・連絡先・広告ID|収集しない。位置の推定は SDK とプロジェクト設定の両方で止め、IP はサービス側で保存しない|—|—|—|

- 「匿名」であるだけでは「ユーザーに関連付けなし」と断定しない。
- アプリの送信イベントや SDK を変えたら、この表、アプリ本体の `app.json` の `ios.privacyManifests`、プライバシーポリシーを照合し直す。
- 根拠: [Apple App Privacy Details](https://developer.apple.com/app-store/app-privacy-details/)。Sentry のインストールIDは、ソフトテニスタクティクスの回答表と同じ根拠（Sentry Cocoa の `SentryClient.m` の `setUserIdIfNoUserSet:`）。
